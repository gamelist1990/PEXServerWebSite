# GeyserPack

Geyser向け配布ファイルを管理するフォルダです。Webサイトの `/GeyserPack/` からダウンロードできます。

- `2DGlass.zip`: Glass Pane 2D v1.0.9。提供されたZIPを変更せず収録しています。
- `2DGlass.mcpack`: 同じ内容でmanifest.jsonをアーカイブ直下に配置した導入用パック。
- `2DGlass.png`: ZIPに同梱されたパックアイコン。

2D Glassは `2DGlass.mcpack` をGeyserの `packs/` に配置し、再起動してください。BedrockではMCPACKを開いてインポートできます。元ZIPは保管用です。

[Geyser公式のパック導入手順](https://geysermc.org/wiki/geyser/packs/)パックの動作は使用中のGeyser / Bedrock環境で確認してください。

CooldownAnimationは [公式Releases](https://github.com/gamelist1990/GeyserCooldownAnimation/releases/latest) で拡張・Paper Bridge・パックをまとめて配布しています。
